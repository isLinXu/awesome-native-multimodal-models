## 1. 和 Any-to-Any 怎么分

| | Any-to-Any | Omni |
| :-- | :-- | :-- |
| 核心问题 | 模态覆盖全不全 | 交互是不是实时、全双工 |
| 典型能力 | 文→图、图→音、视频→文 | 边看边听边说，可打断 |
| 代表 | CoDi, NExT-GPT, AnyGPT | GPT-4o, Qwen2.5-Omni, MiniCPM-o, VITA |

闭源模型（GPT-4o / Gemini）往往没有 arXiv ID，自动抓取会漏。它们被记在 `scripts/data.py` 的时间线里，不进这篇的论文表。
